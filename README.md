# Divina Threading Salon

Local Next.js site for Divina Threading Salon in Sunnyside, Queens.

## Development

```bash
npm install
npm run dev
```

## Verification

```bash
npm run lint
npm run typecheck
npm run build
```

## Assets

All current photography is stored locally in `public/images/gallery/` and was selected from Divina's public Facebook photo gallery and Magicpin business listing. No AI-generated images are included in the site.

Add approved Divina salon, service, and finished-work photos under `public/images/gallery/`, then update `app/data.ts` to include them in the gallery.
